## What you may do without asking

- Use the name `agentsurface` to refer to this project, including in articles,
  talks, comparisons, reviews and academic work.
- Redistribute unmodified official release binaries or unmodified source under
  the name `agentsurface`, keeping the LICENSE and NOTICE files intact.
- Package the unmodified project for a distribution or package manager under
  the name `agentsurface`, provided the package builds from official sources
  and the version corresponds to a released version.
- Say that your software "works with agentsurface", "reads agentsurface JSON
  output", or "is based on agentsurface", in ordinary descriptive English.
- Use the marks in a factual statement about the origin of forked code, for

## What needs permission

- Naming a fork, a derivative work, a modified build or a hosted service
  `agentsurface`, or a name confusingly similar to it. Rename your fork.
- Using **Northbeams** or **Northbeams Labs** in the name of a product,
  company, domain, social account, package namespace or repository.
- Using the logos or wordmarks, altered or unaltered.
- Any use that suggests endorsement, affiliation, certification or partnership
  where none exists, including in advertising, benchmark claims or badges.
- Selling merchandise carrying the marks.

## Modified builds

If you distribute a modified build, you may state factually that it is derived
from agentsurface, but the artefact itself must carry a different name so that
a user can tell which one they are running. This matters more than usual for
this project: the value of the tool rests on a user being able to check what
the binary does, and two different binaries answering to the same name defeats
that.
